# Internship Management Portal

A full-stack internship management platform that helps students browse and apply for internships through a clean and responsive interface.

## Features
- Student Login & Registration
- Internship Listings
- Search and Filter Functionality
- Internship Application System
- Firebase Authentication
- Responsive User Interface
- Real-Time Database Integration

## Tech Stack

### Frontend
- React.js
- JavaScript
- Tailwind CSS
- HTML5
- CSS3

### Backend & Database
- Firebase Authentication
- Firebase Firestore
